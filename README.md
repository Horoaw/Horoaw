## About

I'm an AI algorithm engineer with hands-on experience in model fine-tuning, local model deployment, and reinforcement learning.

I like taking a model beyond the experiment stage and turning it into something that runs reliably. My work covers data preparation, training, evaluation, inference optimization, and deployment. Along the way, I pay attention to model quality, speed, resource usage, and reproducibility.

## What I do

| Area | Experience |
| --- | --- |
| **Model fine-tuning** | Prepare data, set up experiments, adjust hyperparameters, evaluate results, and iterate from a working baseline. |
| **Local deployment** | Set up local runtimes, manage model resources, optimize inference, and build stable, reproducible workflows. |
| **Reinforcement learning** | Explore agent training, reward design, evaluation methods, and practical applications of reinforcement learning. |
| **AI engineering** | Build data pipelines, experiment tools, inference services, and the supporting pieces needed around a model. |
